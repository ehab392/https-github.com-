# متجر حجة بتول
**لأجود أنواع الخُمرة والبخور والعطور**

متجر إلكتروني كامل: واجهة عربية (RTL) متجاوبة + سيرفر Node.js + قاعدة بيانات PostgreSQL + لوحة تحكم للأدمن.

---

## أولًا: شرح المشروع بلغة بسيطة

| الجزء | ما هو |
|---|---|
| `server.js` | ملف تشغيل الموقع |
| `schema.sql` | ملف إعداد قاعدة البيانات (الجداول) — يُنفَّذ تلقائيًا |
| `src/` | كود السيرفر (تسجيل الدخول، المنتجات، الطلبات، رفع الصور) |
| `public/` | صفحات الموقع (الرئيسية، تسجيل الدخول) والتصميم |
| `views/admin.html` | صفحة لوحة التحكم (محمية، لا يفتحها إلا الأدمن) |
| `public/images/logo.png` | شعار المتجر (استبدله بشعارك) |

**لا تحتاج أن تكتب أو تعدّل أي كود.** كل ما عليك: رفع الملفات، ثم ضبط الإعدادات من مواقع الخدمات.

---

## ثانيًا: الخدمات المجانية التي ستحتاجها (أنشئ حسابًا في كل واحدة)

| الخدمة | الرابط | فائدتها |
|---|---|---|
| GitHub | github.com | مخزن الكود |
| Neon | neon.tech | قاعدة البيانات |

## ثالثًا: الخطوات بالتفصيل

### الخطوة 1: ارفع المشروع إلى GitHub

**الأسهل (إن توفر لك كمبيوتر ولو لمدة 10 دقائق):**
1. فُك ضغط ملف `hujjat-batool.zip`.
2. في GitHub: **New repository** ← الاسم `hujjat-batool` ← **Create repository**.
3. اضغط **uploading an existing file** واسحب كل الملفات والمجلدات داخل المشروع ← **Commit changes**.

**من الجوال فقط (عبر Codespaces):**
1. افتح github.com من متصفح الجوال، وفعّل **"موقع سطح المكتب" (Desktop site)** من قائمة المتصفح.
2. أنشئ مستودعًا: **New repository** ← الاسم `hujjat-batool` ← فعّل خيار **Add a README file** ← **Create repository**.
3. داخل المستودع اضغط **Code** ← تبويب **Codespaces** ← **Create codespace on main**. انتظر حتى يفتح المحرر.
4. في قائمة الملفات على اليمين/اليسار، اضغط مطولًا (أو زر الفأرة الأيمن) على مساحة فارغة ← **Upload...** ← اختر `hujjat-batool.zip`.
5. افتح الطرفية (Terminal): من القائمة ☰ ← Terminal ← New Terminal، ثم الصق هذا السطر واضغط Enter:
   ```
   unzip -o hujjat-batool.zip && rm hujjat-batool.zip
   ```
6. ثم الصق هذا السطر:
   ```
   git add . && git commit -m "first version" && git push
   ```
7. تأكد من ظهور الملفات في صفحة المستودع على github.com.

### الخطوة 2: قاعدة البيانات (Neon)
1. في neon.tech: **Create project** ← اكتب أي اسم ← **Create**.
2. ستظهر لك **Connection string** تبدأ بـ `postgresql://`. اضغط **Copy** واحفظها في ملاحظات (هذه قيمة `DATABASE_URL`).
3. لا تُنشئ جداول بنفسك؛ السيرفر ينشئها تلقائيًا عند أول تشغيل.

### الخطوة 3: رفع الصور (Cloudinary)
1. سجّل في cloudinary.com.
2. من لوحة التحكم اختر **Settings** ← **API Keys** (أو "Go to API Keys").
3. انسخ قيمة **API environment variable**، تشبه: `cloudinary://123456:abcdef@mycloud`.
   هذه قيمة `CLOUDINARY_URL`.

### الخطوة 4: نشر الموقع (Render)
1. في render.com: **New +** ← **Web Service** ← اختر مستودع `hujjat-batool` (سيطلب ربط GitHub، وافق).
2. املأ الإعدادات:
   - **Language / Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
3. انزل إلى **Environment Variables** وأضف القيم التالية واحدة واحدة:

| الاسم | القيمة |
|---|---|
| `DATABASE_URL` | الرابط من Neon |
| `JWT_SECRET` | نص عشوائي طويل (40 حرفًا فأكثر) اكتبه بنفسك، لا تشاركه |
| `ADMIN_EMAIL` | بريدك الذي ستدخل به كأدمن |
| `ADMIN_PASSWORD` | كلمة مرور قوية للأدمن (8 أحرف فأكثر) |
| `CLOUDINARY_URL` | الرابط من Cloudinary |
| `WHATSAPP_NUMBER` | رقم واتساب بصيغة دولية بدون + (مثال: `966500000000`) |
| `CURRENCY` | العملة، مثال: `ر.س` |
| `NODE_ENV` | `production` |

4. اضغط **Create Web Service** وانتظر 2 إلى 5 دقائق حتى تظهر عبارة **Live**.
5. افتح الرابط الذي يعطيك إياه Render (مثل `https://hujjat-batool.onrender.com`).

### الخطوة 5: أول استخدام
1. اضغط **تسجيل الدخول** واستخدم `ADMIN_EMAIL` و `ADMIN_PASSWORD`.
2. سيظهر زر **لوحة التحكم** في الأعلى. ادخل وأضف منتجاتك.
3. **الشعار:** في GitHub افتح المجلد `public/images` ← **Add file** ← **Upload files** ← ارفع صورة شعارك باسم `logo.png` بالضبط (سيحل محل الشعار المؤقت). ثم يعيد Render النشر تلقائيًا.

## رابعًا: كيف تستخدم لوحة التحكم

- **إضافة منتج:** تبويب "إضافة منتج" ← اختر بخور أو عطر ← املأ البيانات ← ارفع الصور ← **إضافة المنتج**.
  - **البخور:** لكل حجم: الاسم والسعر والصورة، وزر "إضافة حجم آخر".
  - **العطر:** الاسم والسعر والصورة الرئيسية وصور إضافية.
- **الخصم:** افتح المنتج بزر **تعديل** وأدخل "سعر جديد بعد الخصم". يظهر السعر القديم مشطوبًا ويدخل المنتج قسم **العروض** تلقائيًا. للبخور الخصم يكون لكل حجم على حدة. لإلغاء الخصم امسح خانة الخصم.
- **الأكثر مبيعًا:** زر "إضافة إلى الأكثر مبيعًا" بجانب المنتج.
- **الطلبات:** تبويب "الطلبات" يعرض اسم العميل ورقمه والمنتجات والمجموع، ويمكنك تغيير حالة الطلب. اضغط على رقم الهاتف للاتصال بالعميل.

## خامسًا: ملاحظات مهمة

- **الخادم المجاني ينام** بعد 15 دقيقة بلا زوار، وأول زيارة بعدها قد تأخذ نحو دقيقة. الحل عند الجدية: خطة مدفوعة رخيصة في Render.
- **تغيير كلمة مرور الأدمن لاحقًا:** حساب الأدمن يُنشأ مرة واحدة فقط. لتغييره: في Neon افتح **SQL Editor** ونفّذ `DELETE FROM users WHERE role = 'admin';` ثم غيّر `ADMIN_PASSWORD` في Render واضغط **Manual Deploy**.
- **الدفع:** الطلب في هذه النسخة يُحفظ ثم تتواصل مع العميل لتأكيده والدفع (هذا ما طلبته). لا يوجد دفع إلكتروني.
- **الأمان المطبَّق:** تشفير كلمات المرور (bcrypt)، جلسات محمية (JWT داخل كوكي HttpOnly)، صفحة الأدمن محمية في السيرفر، الأسعار تُحسب من قاعدة البيانات لا من المتصفح، وحد لمحاولات الدخول.
- **لا ترفع ملف `.env` إلى GitHub أبدًا** (مستثنى تلقائيًا). القيم السرية تُوضع في Render فقط.

## سادسًا: حل المشاكل

| المشكلة | الحل |
|---|---|
| Render يظهر Failed | افتح **Logs**؛ الغالب أن `DATABASE_URL` خاطئ أو ناقص |
| الصفحة بيضاء / خطأ 502 | انتظر دقيقة (الخادم يستيقظ) ثم أعد التحميل |
| رفع الصور يفشل | تأكد من `CLOUDINARY_URL` كاملًا، وأن الصورة أقل من 8MB |
| لا يظهر الشعار | تأكد أن الاسم `logo.png` وأنه داخل `public/images` |
| لا أستطيع دخول الأدمن | تأكد من `ADMIN_EMAIL` و `ADMIN_PASSWORD` في Render وأنك لم تغيّرهما بعد أول تشغيل |

## تشغيل على جهاز كمبيوتر (اختياري)
```
npm install
cp .env.example .env     # ثم عدّل القيم داخله
npm start                # ثم افتح http://localhost:3000
```
يلزم تثبيت Node.js 18+ والحصول على رابط قاعدة بيانات (Neon يكفي).
